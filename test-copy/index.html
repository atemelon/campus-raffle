      Organizer guide

      Everything needed to run the raffle, for anyone stepping in. Open a section below. Nothing here is secret; the passphrase is not written on this page.

      1. Signing in
      1. Click Organizer sign-in at the bottom of this page.
      2. Type the organizer passphrase and press Unlock. Get the passphrase from Pavel Romaniko or Ariane Mauroy; it is never sent by the page itself.
      3. The dark Organizer tools panel appears above the prize list, and Draw, Remove, Undo and quantity controls appear on prizes and entries.

      You stay signed in until you close the browser tab. On a shared or projected computer, press Sign out when you step away.

      If the page says the passphrase isn't right, check capital letters. If it says to set ORGANIZER_CODE, the passphrase hasn't been set on the server yet (see "Behind the scenes").

      2. Before the event: prizes
      1. In Organizer tools, fill in Prize (e.g. "Wacom tablet"), optional Details (e.g. "Donated by the Bookstore") and Qty (how many of that item you have), then Add prize.
      2. Repeat for each prize. Attendees see the list right away and tick the prizes they want a chance at.
      3. To change a quantity later, edit the number on the prize card and press Set qty. Don't set it lower than the number already awarded.
      4. Delete… removes a prize, its winners, and takes it off everyone's ticket. Use it only for mistakes.

      Entering is blocked until at least one prize is listed.

      3. Before the event: entry timer

      The timer controls when people can enter and when bonus codes work. Everyone sees the same countdown on the ticket, synced to the server's clock.

      • Opens / Closes + Save times: schedule both ahead of time. Leave Opens empty to open immediately; leave Closes empty to stay open until you close it.
      • Open now: opens entries immediately.
      • Close in 15 / 30 min: starts a countdown everyone can see. Good for announcing "last call".
      • +5 min: extends the closing time.
      • Close now: stops entries immediately.
      • Remove timer: no limits; entries stay open.

      For Oct 27: open entries when doors open (12:00 PM) and announce a "Close in 15 min" about 15 minutes before you plan to draw.

      4. Bonus codes (extra tickets as rewards)

      A bonus code gives one extra ticket in every draw that person entered. Use them as rewards: presenting, exhibiting, posting on the idea board, helping set up or clean up.

      1. In Organizer tools → Bonus codes, choose How many (up to 200 at a time) and an optional Label such as "Presenters" so you can tell batches apart later. Press Make codes.
      2. Press Print unused slips. A sheet opens with cut-out slips, three across. Each has the code and a QR code; print it and cut along the dashed lines. (If nothing opens, allow pop-ups for this site.)
      3. Hand one slip per reward. The person scans the QR (the code fills in by itself) or types the code into Have a bonus code?, along with the name on their entry.
      Rules
      Each code works once. The person must enter the raffle first, with the same name. Codes only work while entries are open. One person can hold at most 3 tickets in total; a code offered to someone already at the limit is not used up, so they can pass the slip on.
      Keeping track
      Show codes lists every code, its label and who used it when. Void cancels a lost or unwanted unused code. Download CSV saves the list.
      Safety
      Codes are never shown on the public page. After 10 wrong codes from one network in 10 minutes, further tries are paused for a few minutes; on shared campus Wi-Fi this can affect a whole room, so ask people to type carefully.
      5. During the event: helping attendees
      • Point people to the raffle page (QR code on the signs, or umlcreativeforum.com/raffle). They enter full name, area of study, and tick prizes.
      • Each name can enter once. Names are matched ignoring capital letters, accents and extra spaces, so "Jordan Alvarez" and "jordan alvarez" are the same person.
      • "Already entered" for a different person with the same name: ask them to add a middle initial.
      • Typo in a name or wrong prizes ticked: find the entry in the list, press Remove, and have them enter again. (Removing also removes any bonus tickets they had, and their used code stays used.)
      • "We couldn't find … in the raffle" on a bonus code: they haven't entered yet, or typed a different name. Have them enter first, or use the exact name shown in the Entries list.
      • "Can't reach the raffle": a connection blip. The page retries every 10 seconds; nothing is lost.

      The Entries list updates every 10 seconds on every screen. A ×2 or ×3 badge means that person has bonus tickets.

      6. Drawing winners
      1. Close entries first: press Close now (or let the timer run out) so nobody enters mid-draw.
      2. Put this page on the projector, signed in. You can use the Hide link on the Organizer tools bar to tuck the controls away; it opens by itself when you draw, so the winner is always shown.
      3. On a prize card, press Draw. Names shuffle briefly, then the winner appears large at the top of Organizer tools and is listed on the prize card.
      4. Press Draw again for each remaining item of that prize. The card shows how many are left.
      • Fairness: only people who ticked that prize can win it, and each ticket is one chance, so a ×3 entry is three times as likely as a ×1 entry.
      • One prize per person: once someone wins, they are skipped in every later draw. Decide your order before you start: people who win an early prize are out of the running for later ones.
      • No-show: press Undo next to that winner. The item is free again and the person goes back into the pool; to keep them out, also Remove their entry. Then press Draw.
      • Draw is greyed out when every item is awarded or nobody eligible is left.
      7. After the event
      1. Record the winners: take a screenshot of the Prizes section (each card lists its winners), and press Download CSV under Bonus codes if you want the code record.
      2. When you're done with this event's data, press Clear entries & winners… and confirm. Prizes stay listed for reuse; edit or delete them as needed. Used codes are cleared; unused printed slips keep working next time.
      3. Press Remove timer or set new times for the next event, then Sign out.

      Clearing can't be undone. Take the screenshot first.

      8. Behind the scenes (for whoever manages the hosting)

      The raffle lives in the raffle folder of the forum site on IONOS web hosting (umlcreativeforum.com points to the csf folder).

      • index.html: this page.
      • api/config.php: settings. ORGANIZER_CODE is the passphrase; AREAS is the list of areas of study (change the dropdown in index.html to match). To change the ticket limit, add a line like const MAX_TICKETS = 4;.
      • api/entries.php, api/bonus.php, api/admin.php, api/lib.php: the server code. Don't edit these unless you know PHP.
      • data/: all entries, prizes, winners, codes and the timer, saved in raffle-data.php. It is locked against public viewing. To back up, download this folder over SFTP or the IONOS file manager. Deleting raffle-data.php resets everything, including prizes.

      When uploading updates, replace files inside the existing raffle folder (don't create a raffle/raffle folder), and never overwrite config.php or data/.
